# Telegram Bot Platform (Sellers ↔ Executors)

Платформенный Telegram-бот на Node.js + Telegraf + MongoDB (Mongoose) для посредничества между селлерами маркетплейсов (Ozon, Wildberries) и исполнителями-покупателями.

## Установка

1. Установите зависимости:
```bash
npm install
```

2. Создайте файл `.env` в корне проекта:
```env
# Telegram Bot Token
BOT_TOKEN=your_bot_token_here

# MongoDB Connection String
MONGODB_URI=mongodb://127.0.0.1:27017/market-platform

# Admin User ID (числовой Telegram ID)
ADMIN_USER_ID=123456789

# Optional: Webhook
WEBHOOK_DOMAIN=
PORT=3000
```

3. Запустите бота платформы (модульная версия):
```bash
npm run start:platform
```

Либо запустите существующий бот из `index.js`:
```bash
npm start
```

## Функции

- Регистрация и выбор роли (Селлер / Исполнитель) при `/start`. Возможность смены/добавления роли.
- Профиль: Telegram ID, имя/ник, рейтинг, баланс, история заданий и отзывов.
- Задания: создание селлером, отклик исполнителя, подтверждение селлером, перевод вознаграждения.
- Финансы: пополнение селлерами (заглушка модуля платёжки), вывод исполнителем с удержанием 4% комиссии, лог транзакций.
- Отзывы и рейтинг с обеих сторон.
- Админ-команды: просмотр пользователей, заданий, балансов, блокировка.
- Уведомления о новых заданиях, подтверждениях, поступлениях.

## Команды бота

- `/start` — регистрация/выбор роли
- `/profile` — профиль пользователя
- `/create_task` — создание задания (селлер)
- `/tasks` — список заданий / отклик исполнителя
- `/withdraw` — вывод средств (исполнитель, комиссия 4%)
- `/rate` — оставить отзыв

## Структура (модульная платформа)

- `src/bot.js` — входная точка бота платформы
- `src/config/index.js` — конфиг и подключение к MongoDB
- `src/models/*.js` — Mongoose-схемы: User, Task, Transaction, Review
- `src/controllers/*.js` — бизнес-логика: users, tasks, finance, reviews
- `src/middlewares/*.js` — rate-limit и загрузка пользователя
- `src/commands/*.js` — реализация команд Telegraf
- `src/utils/*.js` — утилиты (деньги, логгер)

## Пример комиссии 4%

При выводе 1000 ₽ исполнитель получит 960 ₽, комиссия 40 ₽ попадёт в транзакции как `fee`.

Формула: `net = amount * (1 - 0.04)`.

## Безопасность

⚠️ **ВАЖНО**: Никогда не коммитьте файл `.env` в репозиторий! Все секретные данные должны храниться в переменных окружения.

## Структура проекта

- `index.js` — исходный бот проекта (не связан с платформой)
- `src/` — модульная платформа
- `package.json` — зависимости проекта
- `.env` — переменные окружения (создать самостоятельно)
- `.gitignore` — файлы для игнорирования Git
