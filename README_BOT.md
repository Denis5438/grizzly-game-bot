# Telegram Bot - Платформа для заданий

Этот бот реализует платформу для создания и выполнения заданий с системой оплаты, реферальной программой и админ панелью.

## Функциональность

### Основные возможности:
1. **Профили пользователей** с балансом и рейтингом
2. **Система ролей**: Селлер и Исполнитель
3. **Создание и выполнение заданий**
4. **Система отзывов и рейтингов**
5. **Пополнение баланса** с комиссией 0.5% для селлеров
6. **Вывод средств** с комиссией 2%
7. **Реферальная система** с начислениями
8. **Система промокодов**
9. **Админ панель** для управления

### Команды бота:

#### Основные команды:
- `/start` - Начало работы, выбор роли
- `/profile` - Просмотр профиля и балансов
- `/create_task` - Создание задания (для селлеров)
- `/tasks` - Просмотр доступных заданий
- `/accept <id>` - Принятие задания
- `/submit <id>` - Отправка выполненного задания
- `/confirm <id>` - Подтверждение выполнения (для селлеров)
- `/rate <id> <оценка> <комментарий>` - Оценка работы

#### Финансовые команды:
- `/deposit <сумма>` - Пополнение баланса (только селлеры)
- `/deposit_promo <сумма> <промокод>` - Пополнение с промокодом
- `/withdraw <сумма>` - Вывод средств
- `/withdraw_referral <сумма>` - Вывод реферального баланса

#### Реферальная система:
- `/referral` - Статистика рефералов
- `/referral_link` - Получить реферальную ссылку

#### Промокоды:
- `/promo <код>` - Использовать промокод

#### Админ команды:
- `/admin` - Админ панель
- `/create_promo <код> <тип> <значение> [макс_использований]` - Создать промокод
- `/list_promos` - Список промокодов
- `/toggle_promo <код>` - Активировать/деактивировать промокод

## Установка и настройка

### 1. Установка зависимостей:
```bash
npm install
```

### 2. Настройка переменных окружения:
Создайте файл `.env` в корне проекта:
```env
BOT_TOKEN=your_bot_token_here
MONGODB_URI=mongodb://127.0.0.1:27017/market-platform
ADMIN_USER_ID=123456789
PORT=3000
WEBHOOK_DOMAIN=https://yourdomain.com
```

### 3. Запуск:
```bash
npm start
```

## Модели данных

### User (Пользователь):
- `telegramId` - ID в Telegram
- `username` - Имя пользователя
- `roles` - Роли (seller, executor)
- `balance` - Основной баланс
- `referralBalance` - Реферальный баланс
- `referralCode` - Уникальный реферальный код
- `referredBy` - Кто пригласил
- `referralCount` - Количество рефералов
- `rating` - Рейтинг
- `isBlocked` - Заблокирован ли

### Task (Задание):
- `creator` - Создатель (селлер)
- `executor` - Исполнитель
- `description` - Описание
- `rewardAmount` - Размер награды
- `status` - Статус (open, assigned, submitted, confirmed, cancelled)
- `attachments` - Вложения

### Transaction (Транзакция):
- `user` - Пользователь
- `type` - Тип (deposit, withdrawal, reward, fee, referral_bonus, promo_bonus)
- `amount` - Сумма
- `meta` - Дополнительные данные

### PromoCode (Промокод):
- `code` - Код промокода
- `type` - Тип (bonus, discount)
- `value` - Значение
- `maxUses` - Максимальное количество использований
- `usedCount` - Количество использований
- `isActive` - Активен ли

## Система комиссий

- **Пополнение баланса**: 0.5% комиссия (только для селлеров)
- **Вывод средств**: 2% комиссия
- **Вывод реферального баланса**: 2% комиссия

## Реферальная система

- При регистрации по реферальной ссылке начисляется 50 ₽ рефереру
- Реферальный баланс можно выводить отдельно
- Каждый пользователь получает уникальный реферальный код

## Админ панель

Доступна только пользователю с ID, указанным в `ADMIN_USER_ID`:
- Просмотр пользователей и их балансов
- Управление заданиями
- Создание и управление промокодами
- Статистика системы
- Блокировка/разблокировка пользователей
